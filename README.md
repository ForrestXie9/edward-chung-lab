# Urban Mobility Intelligence Laboratory

Static website for Urban Mobility Intelligence Laboratory (UMI Lab).

Open `index.html` locally or publish this repository with GitHub Pages.

The homepage includes a lab introduction, current news, and links to research,
team members, and opportunities. All pages share navigation, a contact footer,
and a locally stored Hong Kong transport photograph.
